# The Mosquitto Game

## Beschreibung
The Mosquitto Game ist ein einfaches Mückenfangspiel, das mit Android Studio entwickelt wurde im Rahmen des Modules 335.

## Zweck des Projekts 

Erste Erfahrungen mit Android Studios machen

## Ausführung des Game

### Option 1 Git Clone oder Zip Datei Herunterladen
1. Git Projekt Herunterladen oder Klonen
<img width="1001" height="357" alt="image" src="https://github.com/user-attachments/assets/d1b0662f-45d6-441b-b7ec-d9c8ca206d53" />
2. Zip Datei extrahieren
3. Projekt in Android Studio öffnen und eine Virtuelle Handy Version auswählen
4. Game Starten und Ausprobieren

## Voraussetzung:
- Installiertes Android Studio
- Genügend RAM zum Starten des Virtuellen Handy minimal 16 GB RAM oder mehr
- Android Handy für die APK Version

### Option 2 Direkt auf dem Handy Installieren
1. Die APK-Datei The-Mosquitto-Game-Version1.0 aus dem Repository herunterladen.
2. Die heruntergeladene APK auf dem Android-Handy öffnen.
3. Falls erforderlich, die Installation aus dieser Quelle erlauben.
4. Die APK installieren.
5. Das The Mosquitto Game öffnen und ausprobieren.
